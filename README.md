### Prérequis
Pour lancer le projet, vous devez avoir :

*   [Yarn](https://classic.yarnpkg.com/en/docs/install/#mac-stable)
*   [Node](https://nodejs.org/fr/) >= 14.17.0

Pour déployer, vous devez avoir :

*   [Deployer](https://deployer.org/)

### Installation
*   Lancer un `$ yarn install`, qui devrait créer un dossier "node_modules"
*   Dupliquer le `.env.sample` et le renommer en `.env`, puis remplir les bonnes informations
*   Lancer un `$ yarn dev` pour lancer le serveur

Et voilà, vous pouvez dorénavant accéder à la WebApp.
